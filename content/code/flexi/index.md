# Flexi

A family of minimal command-line tools, inspired by [todo.txt](https://github.com/todotxt/todo.txt). Each keeps its data in a single human-readable text file, one entry per line, that you can grep, diff, and edit by hand.

It started with time tracking, but the same plaintext approach works for shopping lists and contacts too. Every tool installs on its own, through Cargo or Homebrew.

Source: [thombruce/flexi](https://github.com/thombruce/flexi)
