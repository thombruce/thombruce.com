# clocking

Log working hours as clock-in and clock-out sessions, and total them by day, week, or month.

```sh
cargo install clocking
# or
brew install thombruce/tap/clocking
```

Source: [crates/clocking](https://github.com/thombruce/flexi/tree/main/crates/clocking)
