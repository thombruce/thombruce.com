# bagg

Keep a plaintext shopping list or wishlist, with name, price, quantity, and whether you've got it yet.

```sh
cargo install bagg
# or
brew install thombruce/tap/bagg
```

Source: [crates/bagg](https://github.com/thombruce/flexi/tree/main/crates/bagg)
